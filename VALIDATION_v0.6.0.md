# Проверка 0.6.0

90 автоматических тестов прошли (pytest). Python compileall и node --check app/static/app.js прошли.

Покрыто: литры/шаг/остаток/округление; отдельные кассы; неизменная касса платежа; отбраковка чужого получателя; прежний цикл заказа; маршрутизация ответов в нужную тему и заказ; внутренние сообщения; сохранение автора; закрытие/открытие темы; неопределённое создание темы; перенос локальных фото в S3 и сохранение метаданных при ошибке; реальный SDK boto3 с заглушкой сервера и SigV4-ссылки; экспорт/импорт базы, пустота целевой базы и откат транзакции при ошибке.

Новые тесты базы выполнены на SQLite. Подключение PostgreSQL Timeweb, права реального бакета, создание темы в вашей группе и операции ваших касс не выполнялись: реквизиты не переданы. Docker-образ здесь не собирался; приложен Dockerfile для Bothost. Команды проверки окружения приведены в TIMEWEB_AND_BOTHOST_v0.6.0.md.
