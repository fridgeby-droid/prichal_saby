# Самовывоз 0.5.1 — расписание в боте

Обновите файлы на Bothost, сохранив базу, переменные окружения и постоянную папку data. Пересоберите приложение и переоткройте Mini App.

Добавьте настройки (это также значения по умолчанию):

```dotenv
PICKUP_LOCAL_SCHEDULE=true
PICKUP_OPEN=19:00
PICKUP_CLOSE=02:00
PICKUP_ASSEMBLY_MINUTES=15
PICKUP_TIMEZONE=Asia/Yekaterinburg
TEST_AUTO_PICKUP_TIME=false
```

Расписание единое для всех магазинов, ежедневно. Приём заказов с 19:00 включительно до 01:45 не включительно по Перми; выдача до 02:00. Время готовности назначается автоматически через 15 минут с округлением вверх до минуты. Выбора времени нет. Календарь Saby для оформления не запрашивается. Локальное расписание имеет приоритет над старым тестовым обходом времени.

Вне времени приёма каталог остаётся доступным, оформление закрыто. В каталоге показано ближайшее открытие. Данные обновляются раз в 30 секунд и при открытии корзины. Сервер независимо проверяет время при оформлении и перед созданием нового платежа. При создании платежа обновляется плановое время самовывоза. Фактическая сборка начинается после подтверждения оплаты.

Уже созданные платежи не отменяются этим обновлением: покупатель может завершить открытую оплату после окончания приёма. Подтверждённая оплата обрабатывается обычным образом и заказ передаётся в Saby; позднюю оплату нужно контролировать у продавца. Жёсткое прекращение уже открытых оплат в 01:45 этой сборкой не реализовано.

Настройки Saby должны позволять приём заказа в нужный период. Геопроверка, минимум 1200 ₽, каталог и статусы сохранены. Рабочие платежи автоматически не включаются, продолжайте использовать тестовые ключи.

Проверка после установки: днём показано ближайшее открытие, в 19:00 оформление доступно, при создании тестового заказа время назначается автоматически. Настройки можно временно изменить для теста и вернуть обратно. Команды диагностики Saby остаются только для ручной проверки.

Для отключения местного расписания можно установить PICKUP_LOCAL_SCHEDULE=false — это возвращает прежний механизм времени, поэтому для текущего сценария оставьте true.

Локально: 73 автоматических теста прошли на FastAPI 0.141.1; синтаксис JavaScript проверен. Живые Saby/ЮKassa и интерфейс телефона нужно проверить после установки.
