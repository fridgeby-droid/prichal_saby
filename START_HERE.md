# Причал Самовывоз v0.3 — фото, описания и весовые товары

Эта версия позволяет загрузить настоящие магазины, товары, цены, категории и остатки из выбранных прайсов. Ключи ЮKassa для этого не нужны. APP_MODE=catalog открывает витрину в браузере и Telegram, но отключает создание заказов, оплату, переписку и передачу в Saby. Это публичная витрина: выбирайте только прайсы для покупателей.

## 1. Развернуть на Bothost

Загрузите файлы проекта в отдельный проект Bothost (не поверх Причал Core). Команда запуска `python main.py`, установка зависимостей `pip install -r requirements.txt`. В архиве есть Dockerfile. Сервер слушает 0.0.0.0 и порт из переменной PORT (по умолчанию 8000); используйте порт и HTTPS-адрес, назначенные хостингом.

В переменных окружения Bothost задайте:

```
APP_MODE=catalog
SABY_CLIENT_ID=ID приложения Saby
SABY_APP_SECRET=Защищенный ключ
SABY_SECRET_KEY=Сервисный ключ
PUBLIC_URL=https://адрес-вашего-приложения
SABY_STORE_PRICES={"123":456}
```

123 и 456 — примеры, замените на свои значения. Секреты не вставляйте в код, GitHub или сообщения. Если запускаете локально, скопируйте `.env.example` в `.env` и заполните его; в переменных Bothost файл .env не нужен.

## 2. Узнать ID магазинов и прайсов

После установки зависимостей и добавления трех ключей выполните в терминале проекта:

```
python manage.py saby-points
python manage.py saby-prices 123
```

Первая команда выводит магазины с `id`, вторая — прайсы выбранного магазина (123 замените на его id). Эти команды работают до настройки SABY_STORE_PRICES и не требуют запуска веб-сервера. Выберите именно предназначенный для самовывоза прайс, а не общий ассортимент.

Для нескольких магазинов:

```
SABY_STORE_PRICES={"123":456,"124":789}
```

В поле значения переменной Bothost вставляйте JSON без внешних одинарных кавычек. Магазины, не перечисленные в этой переменной, не отображаются. Названия, адреса и координаты загружаются из Saby при запуске. Для обновления списка магазинов перезапустите приложение.

## 3. Проверить выгрузку

```
python manage.py saby-check
```

Проверка выведет количество поддерживаемых товаров и первые пять позиций с ценами и остатками для каждой точки. Затем запустите/перезапустите приложение и откройте его HTTPS-адрес. При выборе магазина каталог запрашивается из Saby заново. Если Saby недоступен, показывается ошибка; демо-каталог не подставляется.

Чтобы открыть витрину внутри Telegram, укажите ее HTTPS-адрес как Menu Button через BotFather. В режиме каталога BOT_TOKEN не обязателен. Для прежнего демо без ключей используйте APP_MODE=demo.

## Подготовка в Saby

Каталог должен быть опубликован, а нужные позиции включены в прайс точки. Доступы приложения должны разрешать API Retail. Если список точек пуст, проверьте права приложения и настройку рабочего места точки (фискальный регистратор или виртуальная ККТ, согласно документации Saby).

Корзина поддерживает штучные товары (шт, штука, упак, уп) и весовые (кг, г; также kg, g, гр, килограмм, грамм). Минимум 150 г, шаг 50 г; кнопка минус с 150 г удаляет позицию. Цена показывается за 100 г, стоимость — за выбранный вес. При цене за кг в Saby 150 г передаются как 0,15 кг. При цене за г — как 150 г. В базе Saby цена должна соответствовать указанной единице; цену «за 100 г» при единице «кг» нужно исправить в прайсе.

Остатки учитываются с дробной частью; если есть меньше 150 г, добавление запрещено. Сумма каждой строки округляется до копейки. При смене магазина корзина очищается, чтобы не перенести неподходящий вес или количество.

Фото читаются из images API Saby через документированный адрес /retail/img. Ключи остаются на сервере. Используется первое фото, при его отсутствии или ошибке — заглушка. Описание читается из description, HTML преобразуется в текст. Нажатие на товар открывает карточку с описанием и выбором количества. Если Saby не возвращает фото или описание, приложение не придумывает их. При необходимости пришлите название проблемного товара и результат проверки, без ключей.

В режиме catalog корзину теперь можно открыть и проверить суммы; оформление и оплата отключены. Новых переменных для v0.3 не требуется. Обновите файлы проекта, сохранив переменные окружения и постоянный каталог data, затем пересоберите и перезапустите приложение. APP_MODE оставьте catalog.


## Заказы и оплата — последующее подключение

APP_MODE=integration включает прежние интеграции и требует BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET, ключи ЮKassa и остальные параметры из README.md. Не включайте этот режим только ради каталога. Для чатов магазинов предусмотрена SABY_STORE_CHATS={"123":"-100..."}. Требования приемки, чеков, состояний Saby и ограничения возвратов из README остаются в силе.

Реальные ключи пользователя при подготовке этой версии не использовались. Проверено на имитированных ответах API, фактическую выгрузку вашей базы нужно выполнить командами выше.
